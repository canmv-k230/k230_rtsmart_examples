# PUFS host tests

From the examples checkout, run `make -C peripheral/pufs/host check`.
In the SDK layout, the `examples` and `libs` checkouts sit under
`src/rtsmart`; the Makefile uses `libs/rtsmart_hal` from that layout.
For a standalone examples checkout, pass the matching HAL explicitly:

```sh
make -C peripheral/pufs/host check HAL=/path/to/libs/rtsmart_hal
```

The tests need a native C compiler, GNU make, a linker supporting
`--wrap`, pthreads, and the OpenSSL headers and libcrypto
(`libssl-dev` on Debian/Ubuntu). No board or cross compiler is required.

The checked-in `test_pkc_vectors.h` is the canonical fixture and is not
regenerated by `make check`. Regeneration separately requires Python 3
and `cryptography` (`python3-cryptography` on Debian/Ubuntu); see the
generator's docstring before replacing the fixture.
